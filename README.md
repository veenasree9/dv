# Medicine Analytics Dashboard

A Python Streamlit dashboard for medicine inventory and sales analysis.

## Features
- Interactive multiselect filters
- Medicine-wise bar chart
- Inventory category pie chart
- Monthly sales line chart
- Medicine price histogram
- Price vs sales scatter plot
- Summary metrics
- Filtered data table
- CSV download

## Run locally

Install the dependencies:

    pip install -r requirements.txt

Start the application:

    streamlit run app.py

Note: The app uses generated sample data for demonstration.
